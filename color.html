The 7-Step Extraction Process

From raw URL to extracted brand palette using intelligent filtering.

01
1. Website Capture
Automated browser engine renders and takes a high-resolution full-page screenshot of the target URL.
02
2. Code Analysis
Simultaneously scans CSS files to identify colors explicitly defined in the website's source code.
03
3. CV Filtering
OpenCV removes photos, logos, and decor using edge detection to isolate UI elements.
04
4. ML Extraction
K-Means Clustering samples 8,000 pixels and groups them in the LAB color space.
05
5. Smart Filtering
Eliminates similar shades and standard backgrounds (white/black) to find distinct colors.
06
6. Intelligent Matching
Cross-references visually extracted colors with CSS code to validate brand accuracy.
07
7. Prioritization
Ranks final results (Brand > Accent > UI) to return the top 3 defining colors.
