The Process: From Data to Insights

A fully automated pipeline handling up to 500 cases per batch.

1. Data Retrieval
System fetches raw dialogue text and metadata from the database based on input IDs.
2. Preparation
Raw text is cleaned, normalized, and split into individual sentences for granular analysis.
3. AI Processing
DistilBERT analyzes sentence batches, generating probability scores for 43 categories.
4. Aggregation
Sentence-level predictions are combined using voting thresholds to determine the main theme.
5. Response
Final classifications (e.g., Transportation, Safety) are saved and returned via API.
